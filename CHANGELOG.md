# Changelog

## 0.1.0 (Unreleased)

### Added
- IPC Server: Unix socket (macOS/Linux) + HTTP fallback (Windows), JSON-RPC 2.0
- CLI Tool: `vmux` — notify, terminal control, session management
- Agent Notification System: StatusBar badge, Notifications TreeView, system notifications
- Terminal Session Management: save/restore named presets, split group support, auto-restore
- Environment Context Injection: `VMUX_*` variables, TerminalProfileProvider
- Sidebar: Activity Bar icon with Notifications, Terminals, Sessions TreeViews
- Keyboard shortcut: `Cmd+Shift+U` / `Ctrl+Shift+U` — jump to latest notification
